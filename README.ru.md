# background-browser-skill-macos

[English version](README.md)

Скилл `/browser` для **Claude Code** и **Codex**: агент работает сразу на нескольких сайтах (ChatGPT, Gemini, Google Flow, любое веб-приложение) в **фоновых вкладках свёрнутого Google Chrome**. Фокус у вас не забирает, токенов тратит мало. Основан на [playwright-cli](https://github.com/microsoft/playwright-cli) от Microsoft.

## Какие проблемы решает

| Проблема | Что делает скилл |
|---|---|
| Chrome всплывает и забирает фокус, пока вы работаете | Запускает Chrome один раз, сворачивает и возвращает фокус в ваше приложение. Новые вкладки открываются в фоне. Всплывающие окна (`target=_blank`, `window.open`) остаются в той же вкладке. |
| Агент проходит сайты по очереди | Своя сессия playwright-cli на каждый сайт, все подключены к одному браузеру и работают параллельно. |
| Сайты за Cloudflare блокируют headless Chrome | Настоящий видимый Chrome с постоянным профилем, просто свёрнутый. Никаких трюков для обхода защиты от ботов. |
| Скриншоты и огромные снимки страниц сжигают токены | `page-snap.sh` сначала даёт короткий обзор (обычно меньше 500 токенов), потом только нужный блок. Полный снимок тяжёлой страницы стоит 8-20 тысяч токенов. |
| Приходится входить снова и снова | Постоянный профиль помнит входы. Вход и капчу вы делаете сами, один раз. |
| Агент берёт случайный браузерный инструмент | Один скилл с понятными правилами: сначала playwright-cli, встроенные браузеры и Computer Use только по просьбе. |

## Чем лучше официального скилла playwright-cli

Официальный скилл это справочник команд, и он входит в этот скилл. Он подключён ссылкой из установленного пакета, поэтому всегда совпадает с вашей версией CLI. Сверху добавлены правила (профили, headless и видимый режим, сохранение входов, бюджет токенов) и четыре небольших скрипта:

- `browser-up.sh`: запускает или переиспользует свёрнутый Chrome, возвращает фокус, ставит защиту от всплывающих окон, открывает сайты в фоновых вкладках. Если браузер на этом профиле уже запущен (даже из другого проекта), подключается к нему, а не падает на блокировке профиля.
- `bg-tab.sh`: открывает ещё фоновые вкладки.
- `page-snap.sh`: дешёвый по токенам снимок вкладки, выбранной по адресу (`--depth`, `--ref`, `--grep`, `--interactive`).
- `browser-hide.sh`: снова убирает окно.

В видимом режиме нельзя использовать `tab-new`, `tab-select` и `bringToFront`: они выводят Chrome на передний план. Скилл сообщает это агенту.

## Сравнение с другими способами дать агенту браузер

Цифры токенов примерные. «Замерено» значит, что мы измерили это для нашего скилла. Остальное взято из публичных отчётов (ссылки ниже) или оценено по размеру скриншота (около 1,2-1,6 тысячи токенов за скриншот).

| Инструмент | Как агент видит страницу | Токенов на чтение страницы | Забирает фокус / мешает | Ваши входы | Параллельно несколько сайтов | Работает из CLI-агентов |
|---|---|---|---|---|---|---|
| **Этот скилл** | текстовый снимок с ref, сначала неглубокий | **300-500 обзор, 1-2 тыс. для ChatGPT/Gemini (замерено)**; загрузка скилла около 6 тыс. один раз | нет (свёрнут, фоновые вкладки) | да, свой постоянный профиль | да, сессия на сайт | да (Claude Code, Codex CLI) |
| Официальный скилл playwright-cli | текстовый снимок в файле | 1-20 тыс., если читать весь файл | в видимом режиме да (новые вкладки выходят вперёд) | да | вручную | да |
| Playwright MCP | снимок после каждого действия | 3-15 тыс. на действие, плюс около 13 тыс. на описание инструментов | в видимом режиме да | по желанию | ограниченно | да |
| Chrome DevTools MCP (Google) | снимок a11y или скриншот | снимок 0,3-10 тыс., скриншот около 1,6 тыс.; `--slim` урезает описания | подключается к вашему Chrome | да | ограниченно | да |
| agent-browser (Vercel) | компактный снимок с ref | 0,2-0,4 тыс. снимок интерактивных элементов (по отчётам) | в видимом режиме да | по желанию | сессии | да |
| Browser Use CLI / Browser Harness | CDP-хелперы в вашем Chrome | меньше всех в их собственном бенчмарке (2,1 млн против 4,4 млн у Playwright MCP за набор задач) | работает в вашем Chrome | да, ваш профиль | да | да |
| Claude in Chrome (расширение) | дерево a11y (`read_page`) плюс скриншоты | сотни или несколько тысяч на дерево, около 1,5 тыс. за скриншот; по умолчанию часто скриншоты | работает в вашем видимом Chrome | да, ваш профиль | группа вкладок | через `--chrome` |
| Расширение ChatGPT/Codex для Chrome | DOM плюс скриншоты (не документировано) | публичных данных нет | работает в вашем видимом Chrome | да, ваш профиль | группы вкладок | только десктопное приложение |
| Встроенный браузер Claude Code Desktop | DOM плюс скриншоты | около 1,2-1,6 тыс. за скриншот | нет (внутри приложения) | нет, чистый профиль | вкладки | только десктопное приложение |
| Встроенный браузер Codex/ChatGPT | DOM плюс скриншоты | около 1,2-1,6 тыс. за скриншот | нет (внутри приложения) | нет, отдельный профиль | вкладки | только десктопное приложение |
| Computer Use (Claude, Codex) | скриншоты экрана | около 1,2-1,6 тыс. за шаг | да, использует ваш экран | что открыто | нет | частично |
| Инструменты на дереве доступности (Cua Driver, Peekaboo) | дерево доступности приложений | мало (ref элементов вместо пикселей) | Cua: ввод в фоне | не применимо | не применимо | да (MCP/CLI) |

Коротко: для сайтов дешевле всего CLI с текстовыми снимками (этот скилл, agent-browser, Browser Use CLI). Встроенные браузеры удобны для быстрой проверки своего localhost. Computer Use нужен только для десктопных приложений без API. Приложения на холсте вроде Figma отдают текстом только интерфейс: для холста нужны скриншоты или Figma API.

## Установка

Нужно: macOS, Google Chrome, Node.js 20+, Claude Code и/или Codex.

**Попросите агента** (Claude Code или Codex):

> Установи browser skill из https://github.com/mchibisov/background-browser-skill-macos: склонируй во временную папку, прочитай INSTALL.md и выполни.

**Или вручную:**

```bash
git clone https://github.com/mchibisov/background-browser-skill-macos.git
cd background-browser-skill-macos && ./install.sh
```

Установщик ставит `@playwright/cli`, если его нет, и подключает официальный скилл playwright-cli ссылкой. `~/.playwright/cli.config.json` (Google Chrome) он пишет, только если такого файла ещё нет. Ещё создаёт `~/playwright-profiles/` и запускает самопроверку в headless. Повторный запуск безопасен. Подробности и ручные шаги: [INSTALL.md](INSTALL.md).

## Как пользоваться

В новой сессии: `/browser` в Claude Code, `$browser` в Codex, или просто попросите сделать что-то в браузере. Пример:

> Открой ChatGPT и Gemini в фоне, отправь обоим один и тот же запрос и сохрани ответы в answers.md.

Первый раз на сайте агент развернёт окно и попросит вас войти. Потом свернёт его и продолжит.

## Статус и ограничения

- Проверено на macOS 27, Chrome 157, playwright-cli 0.1.25: фокус не уходил из вашего приложения, кроме примерно секунды при запуске; окно оставалось свёрнутым; три сессии работали параллельно.
- Linux и Windows не проверялись. Сворачивание и фоновые вкладки сделаны через Chrome DevTools Protocol и могут работать. Возврат фокуса есть только на macOS.
- Вход, капчу и 2FA делаете вы. Скилл никогда не пытается обойти защиту от ботов.
- Используется отдельный профиль Chrome (`~/playwright-profiles/default`), ваш основной профиль не трогается.
